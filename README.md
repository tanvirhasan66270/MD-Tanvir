- 🏛️ Experienced in enterprise-grade software development with emphasis on reliability, maintainability, and business process alignment
- 🎓 MBA and BBA in Management from Govt. Bangla College, University of Dhaka
- 💼 Trained through the IDB-BISEW IT Scholarship in Java, Spring Boot, Android, and Flutter
- ☕ Specializing in Java + Spring Boot backend services with Angular admin interfaces and Android/Flutter client apps
- 🎯 Interested in enterprise and fintech software development opportunities
- 🌍 Based in Bangladesh (UTC+06:00), bilingual in Bengali and English
